Use the Playground library first.

The CYD display should teach the functions customers already get when they install PulseSensor Playground. The library handles sampling, beat detection, BPM, IBI, pulse amplitude, and serial formats. Your display code should read those values and explain them visually.

pulseSensor.analogInput(pin)

Selects the analog pin connected to the purple PulseSensor signal wire.

pulseSensor.setThreshold(550)

Sets the default beat threshold. This is the first knob to teach when signal detection is noisy.

pulseSensor.begin()

Starts library sampling and processing. On ESP32, use 10-bit ADC readings for the expected 0-1023 range.

getLatestSample()

Raw PPG sample. Draw this as the live waveform so people trust what the sensor is reading.

sawStartOfBeat()

Returns true once per detected heartbeat. Use this to place beat dots and update IBI/HRV buffers.

getBeatsPerMinute()

The familiar headline number. The library derives BPM from recent IBI values.

getInterBeatIntervalMs()

The key HRV ingredient: milliseconds between beats. A tachogram is simply this value over time.

getPulseAmplitude()

Peak-to-trough amplitude from the latest pulse wave. Useful for a simple signal-quality cue.

getLastBeatTime()

Beat time in sample units with 2 ms resolution. Useful for timing lessons and multi-sensor projects.

From PPG to HRV

Keep the data story visible. HRV is not measured directly from one pulse wave; it is computed from the changing rhythm between consecutive beat detections.

1. Live PPGUse getLatestSample() to show the raw pulse waveform.
2. Beat eventsawStartOfBeat() marks the moment the algorithm found a pulse.
3. IBIgetInterBeatIntervalMs() returns the time between those beats.
4. TachogramStore the last 30-60 clean IBIs. Each bar is one heartbeat.
5. HRV summaryCompute RMSSD, SDNN, and pNN50 from the same IBI buffer.

Build it on CYD

The CYD is a small 320 x 240 touch display, so the best tutorial teaches one layer at a time: signal first, then beats, then IBI, then HRV.

1. Install

In Arduino IDE, open Library Manager and install or update PulseSensor Playground.

2. Wire

PulseSensor red to 3.3V, black to GND, purple signal wire to an available analog input on your ESP32/CYD build.

3. Configure

Call analogReadResolution(10) on ESP32 so the display and threshold logic use the library's expected 0-1023 sample range.

4. Teach

Start with live signal and beat dots. Add tachogram and HRV only after users understand IBI.

Starter code for the article

This is the teaching core. It uses the Playground library for sampling and beat detection, then adds a small IBI buffer for tachogram and HRV metrics.

What this code teaches

  • The library owns the hard part: sampling and beat detection.
  • The display code reads values with clear API calls.
  • HRV metrics are computed from IBI values, not from a single raw pulse wave.
  • The same buffer can drive both a tachogram and numeric summaries.
Important for ESP32

Call analogReadResolution(10). The Playground examples note that ESP32 defaults to 12-bit ADC readings, while the library works with 10-bit values.

#include <PulseSensorPlayground.h>

const int PULSE_INPUT = A0;
const int PULSE_BLINK = 13;
const int THRESHOLD = 550;

PulseSensorPlayground pulseSensor;

const int IBI_COUNT = 60;
int ibiBuffer[IBI_COUNT];
int ibiIndex = 0;
int ibiSeen = 0;

void setup() {
  Serial.begin(115200);

  // ESP32 ADC defaults to 12-bit. PulseSensor Playground expects 10-bit.
  analogReadResolution(10);

  pulseSensor.analogInput(PULSE_INPUT);
  pulseSensor.blinkOnPulse(PULSE_BLINK);
  pulseSensor.setThreshold(THRESHOLD);

  if (!pulseSensor.begin()) {
    while (true) {
      digitalWrite(PULSE_BLINK, !digitalRead(PULSE_BLINK));
      delay(50);
    }
  }
}

void loop() {
  int signal = pulseSensor.getLatestSample();
  drawLivePpgSample(signal);

  if (pulseSensor.sawStartOfBeat()) {
    int bpm = pulseSensor.getBeatsPerMinute();
    int ibi = pulseSensor.getInterBeatIntervalMs();
    int amp = pulseSensor.getPulseAmplitude();

    addIbi(ibi);
    drawBeatDot();
    drawBpm(bpm);
    drawTachogram(ibiBuffer, min(ibiSeen, IBI_COUNT));
    drawSignalQuality(amp);
    drawHrv(calculateRmssd(), calculateSdnn(), calculatePnn50());
  }
}

void addIbi(int ibi) {
  if (ibi < 300 || ibi > 2000) return; // simple artifact guard
  ibiBuffer[ibiIndex] = ibi;
  ibiIndex = (ibiIndex + 1) % IBI_COUNT;
  ibiSeen++;
}

float calculateRmssd() {
  int count = min(ibiSeen, IBI_COUNT);
  if (count < 3) return 0;

  float sumSquares = 0;
  int pairs = 0;
  for (int i = 1; i < count; i++) {
    int now = ibiBuffer[(ibiIndex - i + IBI_COUNT) % IBI_COUNT];
    int prev = ibiBuffer[(ibiIndex - i - 1 + IBI_COUNT) % IBI_COUNT];
    float diff = now - prev;
    sumSquares += diff * diff;
    pairs++;
  }
  return sqrt(sumSquares / pairs);
}

Tachogram

HRV summary
